# 18 — Python GUI Projects

Репозиторий содержит три учебных проекта, разработанных на Python в рамках семинара № 18 «Графический интерфейс пользователя».

Проекты демонстрируют создание графических интерфейсов, обработку пользовательского ввода, работу с файлами, визуализацию данных и разделение логики приложения.

## Содержание репозитория

В репозитории представлены три самостоятельных приложения:

1. **Calculator** — графический калькулятор.
2. **MedCarta** — приложение для учёта информации о пациентах.
3. **FASTQ Analyzer** — программа для анализа файлов биологических последовательностей FASTQ.

Каждый проект находится в отдельной директории и может запускаться независимо от остальных.

## Используемые технологии

- **Python 3** — основной язык программирования.
- **CustomTkinter** — создание графических интерфейсов.
- **Tkinter** — стандартная библиотека Python для создания оконных приложений.
- **Matplotlib** — построение графиков.
- **Pandas** — обработка и анализ табличных данных.
- **Pillow** — открытие и отображение изображений.
- **tkinterdnd2** — поддержка перетаскивания файлов Drag & Drop.
- **JSON** — хранение информации о пациентах.
- **Argparse** — обработка аргументов командной строки.

## 1. Calculator — графический калькулятор

Графическое приложение-калькулятор, реализованное с использованием библиотеки CustomTkinter.

### Возможности

- Ввод выражений с помощью кнопок интерфейса.
- Ввод выражений с клавиатуры.
- Сложение.
- Вычитание.
- Умножение.
- Деление.
- Извлечение квадратного корня.
- Удаление последнего символа.
- Очистка поля ввода.
- Вывод результата.
- Обработка некорректного ввода и математических ошибок.

### Запуск

Из корневой директории репозитория:

```bash
cd calculator
python controller.py
```

## 2. MedCarta — приложение для учёта пациентов

Графическое приложение для ведения списка пациентов и формирования сводной статистики.

Приложение использует архитектуру MVC, разделяющую работу с данными, интерфейс и обработку действий пользователя.

### Возможности

- Отображение информации о пациентах в таблице.
- Добавление новых записей.
- Редактирование информации о существующих пациентах.
- Проверка корректности введённых данных.
- Расчёт индекса массы тела (ИМТ).
- Сохранение информации в JSON-файл.
- Загрузка сохранённых записей при запуске программы.
- Очистка списка пациентов.
- Построение статистических графиков.

### Информация о пациентах

Для каждой записи предусмотрены следующие поля:

- фамилия;
- имя;
- отчество;
- возраст;
- пол;
- рост;
- вес;
- индекс массы тела.

### Статистические графики

Приложение формирует четыре графика:

1. Распределение пациентов по полу.
2. Распределение пациентов по возрасту.
3. Распределение ИМТ с учётом пола.
4. Зависимость ИМТ от возраста.

### Хранение данных

Данные сохраняются в файле:

```text
medcarta/patients.json
```

При запуске программы файл автоматически загружается. При добавлении, редактировании или удалении записей изменения сохраняются.

В репозитории используется демонстрационный набор данных. Не следует хранить в публичном репозитории реальные персональные или медицинские данные.

### Запуск

Из корневой директории репозитория:

```bash
cd medcarta
python main.py
```

## 3. FASTQ Analyzer — анализатор биологических данных

Графическое приложение для анализа файлов формата FASTQ, созданное на основе модуля чтения биологических файлов.

Программа использует существующий модуль `FastqReader` и предоставляет графический интерфейс для выбора файла, получения статистики и построения графика качества.

### Возможности

- Выбор FASTQ-файла через стандартный диалог открытия файлов.
- Фильтрация файлов по расширениям `.fastq` и `.fq`.
- Выбор файлов из списка доступных файлов проекта.
- Перетаскивание файлов в окно программы (Drag & Drop).
- Подсчёт количества последовательностей.
- Вычисление средней длины последовательностей.
- Построение графика среднего качества прочтений по позициям.
- Отображение графика непосредственно в интерфейсе.

### Графический интерфейс

Для запуска графического режима используется параметр `--gui`.

```bash
python main.py --gui
```

После запуска можно выбрать файл из выпадающего списка, открыть его через диалог выбора или перетащить в специальную область интерфейса.

После выбора файла необходимо нажать кнопку обработки. Программа отобразит статистику и график качества.

### Командная строка

Приложение также поддерживает работу без графического интерфейса.

Общий формат команды:

```bash
python main.py -i "путь_к_файлу.fastq" -a действие
```

Доступные действия:

| Действие | Назначение |
|---|---|
| `count` | Подсчёт количества последовательностей |
| `avg_len` | Вычисление средней длины последовательности |
| `plot` | Построение графика качества |
| `all` | Выполнение всех операций |

Примеры:

Подсчёт последовательностей:

```bash
python main.py -i "sample_high_quality.fastq" -a count
```

Вычисление средней длины:

```bash
python main.py -i "sample_high_quality.fastq" -a avg_len
```

Построение графика:

```bash
python main.py -i "sample_high_quality.fastq" -a plot
```

Полный анализ:

```bash
python main.py -i "sample_high_quality.fastq" -a all
```

Для просмотра справки:

```bash
python main.py --help
```

### График качества

График строится на основе оценок качества FASTQ-прочтений.

Результат сохраняется в файл:

```text
quality_plot.png
```

По горизонтальной оси отображаются позиции нуклеотидов, по вертикальной — средние оценки качества для соответствующих позиций.

В графическом режиме созданное изображение дополнительно отображается в окне приложения.

## Установка и запуск

Ниже приведена инструкция для Ubuntu/Linux.

### 1. Установка системных компонентов

Обновите список пакетов:

```bash
sudo apt update
```

Установите Python, поддержку виртуальных окружений и Tkinter:

```bash
sudo apt install python3 python3-venv python3-pip python3-tk
```

### 2. Клонирование репозитория

Перейдите в директорию, в которой хотите разместить проект, и выполните:

```bash
git clone https://github.com/Yolka1/18.git
```

Перейдите в папку проекта:

```bash
cd 18
```

### 3. Создание виртуального окружения

Создайте виртуальное окружение:

```bash
python3 -m venv .venv
```

Активируйте его:

```bash
source .venv/bin/activate
```

После активации в начале строки терминала появится обозначение `(.venv)`.

### 4. Установка библиотек

Обновите pip:

```bash
python -m pip install --upgrade pip
```

Установите зависимости проекта:

```bash
python -m pip install -r requirements.txt
```

Все три приложения используют общее виртуальное окружение. Создавать отдельное окружение внутри каждой папки не требуется.

### 5. Запуск приложений

После установки зависимостей можно запускать любой из трёх проектов.

**Калькулятор:**

```bash
cd calculator
python controller.py
```

**Медицинская карточка:**

```bash
cd ../medcarta
python main.py
```

**FASTQ Analyzer:**

```bash
cd ../fastq
python main.py --gui
```

Для работы с командной строкой FASTQ Analyzer:

```bash
python main.py --help
```

### 6. Завершение работы

Для выхода из виртуального окружения выполните:

```bash
deactivate
```

Это отключает окружение, но не удаляет его.

## Примечания

- Для работы с графическими интерфейсами требуется установленный Tkinter.
- Для построения графиков используется Matplotlib.
- FASTQ Analyzer поддерживает графический и командный режимы.
- Для Drag & Drop используется дополнительная библиотека `tkinterdnd2`.
- Файл `patients.json` содержит демонстрационные данные и изменяется при работе приложения.
- Файл `quality_plot.png` создаётся автоматически при построении графика.
- Виртуальное окружение `.venv` не включается в репозиторий Git.
